## 🧑‍💻 Sobre mí

**Desarrollador Backend Java** con **3 años de experiencia** construyendo sistemas escalables y seguros con **Spring Boot**, para aplicaciones críticas como gestión de nómina, maquinaria y flujos del sector bancario.

- 🏗️ **Arquitecturas limpias y mantenibles:** Hexagonal, Clean Architecture, microservicios y APIs REST.
- ⚡ **Servicios reactivos** con Spring WebFlux y Project Reactor (**~3x más solicitudes concurrentes**) y mensajería asíncrona con RabbitMQ.
- 🔐 **Seguridad** con Spring Security, JWT, cifrado y control de acceso por roles (RBAC).
- 🚀 **Rendimiento:** caché con Redis que redujo **~70% los tiempos de respuesta**.

- 🧪 **Calidad:** JUnit 5, Mockito y Testcontainers (**~90% de cobertura, 100% en la capa de dominio**).
- ⚛️ **Full stack** con React, Vite y Tailwind CSS.

## 💼 Experiencia

### 🏢 Desarrollador Backend Java · **Avantech**
`Feb 2024 — Feb 2026`

- 🏗️ Estructuré la **arquitectura core del backend** con Java y Spring Boot bajo un enfoque de microservicios y APIs REST, garantizando escalabilidad y alta disponibilidad.
- 🔌 Implementé **arquitectura hexagonal** (puertos y adaptadores) para desacoplar el dominio de la infraestructura, mejorando la mantenibilidad y la capacidad de prueba.
- ⚡ Desarrollé servicios **reactivos no bloqueantes** con **Spring WebFlux** y **Project Reactor**, soportando **~3x más solicitudes concurrentes** en endpoints de alta demanda.
- 📨 Implementé **mensajería asíncrona** entre microservicios con **RabbitMQ**, habilitando una arquitectura orientada a eventos.
- 🚀 Optimicé la API con caché **Redis / Spring Cache** para consultas recurrentes, reduciendo los tiempos de respuesta en **~70%**.
- 🔐 Implementé el ecosistema de seguridad con **Spring Security y JWT**, con cifrado robusto (**BCrypt / AES**).
- 🛡️ Diseñé autorización basada en roles (**RBAC**) con validación granular por endpoint, aislando la información entre empresas (multi-tenant) y usuarios.
- 🔄 Orquesté pipelines de **CI/CD en Azure DevOps** para compilación, pruebas y despliegue continuo, llevando los despliegues de horas a **menos de 10 minutos**.
- 🤝 Creé **mocks dinámicos** de la API para que el frontend se integrara en paralelo, acortando **~40%** los tiempos de integración.

### 🏢 Desarrollador Full Stack y QA · **SIGMA**
`Ene 2023 — Ene 2024` · *Sistema de Gestión de Maquinaria y Nómina*

- 🏗️ Diseñé la **arquitectura core** con Java y Spring Boot, estructurando los módulos de mantenimiento, telemetría y pagos.
- 🧱 Apliqué **Clean Architecture** para aislar las reglas de negocio de los frameworks y la persistencia.
- ☁️ Diseñé funciones **serverless con AWS Lambda** para procesos bajo demanda, con **~40% menos** en costos de infraestructura de esos procesos.
- ⏱️ Automaticé el cálculo de nómina y horas trabajadas con **Spring Batch**, reduciendo **~90%** el tiempo frente al proceso manual.
- 🔐 Aseguré la información sensible de pagos y empleados con **Spring Security** y autenticación **JWT**.
- 🐳 Diseñé pipelines **CI/CD con Docker**, desde las ramas de funcionalidades hasta el entorno **Dokploy**.
- 🧪 Integré **Testcontainers, JUnit 5 y Mockito**, alcanzando **~90% de cobertura** (100% en la capa de dominio) con el backend completamente aislado.
- ⚛️ Estructuré el frontend modular con **React y Vite**, organizado por dominios de negocio, con interfaces condicionales por rol (**RBAC**).
- 🎨 Construí una librería interna de **más de 30 componentes** reutilizables con **Tailwind CSS**.
