## 🧑‍💻 Sobre mí

Desarrollador **Backend** con **tres años de experiencia** construyendo sistemas escalables y seguros en el ecosistema de **Java y Spring Boot**. Diseño arquitecturas robustas aplicando **Arquitectura Hexagonal** y **Clean Architecture**, desarrollo servicios **reactivos no bloqueantes** con Spring WebFlux y comunico microservicios con **mensajería asíncrona** usando RabbitMQ.

Implemento flujos de seguridad avanzados con **JWT** y autorización granular **RBAC**, soluciones **serverless** con AWS Lambda, optimizo el rendimiento con **caché** y automatizo despliegues con **CI/CD**. Me comprometo con la excelencia técnica y la calidad a través de **pruebas automatizadas**.

## 💼 Experiencia

### 🏢 Desarrollador · **Avantech**
`Feb 2024 — Feb 2026`

- 🏗️ Estructuré la **arquitectura core del backend** con Java y Spring Boot bajo un enfoque de microservicios, garantizando escalabilidad y alta disponibilidad.
- 🔌 Implementé **arquitectura hexagonal** (puertos y adaptadores) para desacoplar el dominio de la infraestructura, mejorando la mantenibilidad y la capacidad de prueba.
- ⚡ Desarrollé servicios **reactivos no bloqueantes** con **Spring WebFlux** y **Project Reactor** para endpoints de alta demanda.
- 📨 Implementé **mensajería asíncrona** entre microservicios con **RabbitMQ**, habilitando una arquitectura orientada a eventos.
- 🚀 Optimicé los tiempos de respuesta de la API con caché **Redis / Spring Cache** para consultas recurrentes.
- 🔐 Implementé el ecosistema de seguridad con **Spring Security y JWT**, con encriptación robusta (**BCrypt / AES**).
- 🛡️ Diseñé autorización basada en roles (**RBAC**) con validación granular por endpoint, aislando la información entre empresas y usuarios.
- 🔄 Orquesté pipelines de **CI/CD en Azure DevOps** para compilación, pruebas y despliegue continuo.
- 🤝 Gestioné **mocks dinámicos** para una integración transparente y en paralelo con el equipo de frontend.

### 🎓 Desarrollador y QA · **Proyecto Integrador SIGMA**
`Ene 2023 — Ene 2024` · *Sistema de Gestión de Maquinaria y Nómina*

- 🏗️ Diseñé la **arquitectura core** con Java y Spring Boot, estructurando los módulos de mantenimiento, telemetría y pagos.
- 🧱 Apliqué **Clean Architecture** para aislar las reglas de negocio de los frameworks y la persistencia.
- ☁️ Diseñé funciones **serverless con AWS Lambda** para procesos bajo demanda con consumo de recursos optimizado.
- ⏱️ Automaticé el cálculo de nómina y horas trabajadas con procesos programados en **Spring Batch**.
- 🔐 Aseguré la información sensible de pagos y empleados con **Spring Security** y autenticación **JWT**.
- 🐳 Diseñé pipelines **CI/CD con Docker**, desde las ramas de funcionalidades hasta el entorno **Dokploy**.
- 🧪 Aislé completamente el backend en pruebas integrando **Testcontainers, JUnit 5 y Mockito**.
- ⚛️ Estructuré el frontend modular con **React y Vite**, organizado por dominios de negocio.
- 🎨 Construí una librería interna de componentes con **Tailwind CSS** e interfaces condicionales por rol (**RBAC**).
